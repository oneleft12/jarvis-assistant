J.A.R.V.I.S. — Windows Assistant

Голографический HUD-интерфейс персонального помощника в духе Джарвиса из «Железного человека»: кибер-дождь, пульсирующее ядро, живая статистика системы, чат с разбором команд и терминал. Фронтенд — чистый HTML/CSS/JS, бэкенд — Node.js + Express, доступ из интернета — через Cloudflare Tunnel.

Все действия — смена темы, переключение дождя, быстрые команды и журнал — синхронизируются с сервером в реальном времени.

Модули системы

CORE REACTOR

Пульсирующее ядро-реактор. Плавный синхронный разгон колец за 3 сек, каждый клик поднимает потолок до x25. На пределе — перегрузка, красная тряска и взрыв с перезагрузкой.

CYBER RAIN

Неоновый дождь на Canvas: градиентные капли с хвостами, позади всех панелей (z-index: -1). Цвет следует за темой, включается/выключается кнопкой и командой rain.

NEURAL CHAT

Окно общения с Джарвисом. Команды разбирает серверный jarvisBrain: темы, дождь, help, браузер, игра, скриншот, сканирование — действия применяются и на клиенте, и в состоянии сервера.

TERMINAL

Командная строка HUD. Серверные: help, ping, theme, rain, status, clear. Локальные: game, scan, open, time, date, echo, screenshot, about, whoami, sudo.

SYSTEM MONITOR

Метрики каждые 2 секунды: CPU — os.loadavg() к числу ядер, RAM — totalmem/freemem, Network — имитация 5–95 Мбит/с с плавным изменением.

THEME ENGINE

Четыре темы (cyan, matrix, violet, amber) на CSS-переменных: панели, кнопки, ядро и дождь перекрашиваются мгновенно. Выбор хранится в localStorage и на сервере.

REST API

POST/api/chatтело { message } → { reply, action } — ответ Джарвиса и действие (тема/дождь)
GET/api/system→ { cpu, ram, network } — метрики каждые 2 сек
POST/api/commandтело { action } → { status, message } — open_browser | launch_game | screenshot | system_scan
POST/api/terminalтело { command } → { output, clear } — help, ping, theme, rain, status, clear
GET/api/state→ { theme, rain, online, uptime, logs } — состояние и журнал (50 записей)
POST/api/authтело { pin } → { ok: true } | 401 — остальной /api/* требует заголовок x-jarvis-pin
GET/api/plugins→ { commands: [{ cmd, desc, plugin }] } — реестр плагинов
POST/api/scoresтело { game, score, name } → таблица рекордов (runner|memory|snake), GET ?game= — топ-10
